# 통합 연구보고서 에이전트

연구자의 실제 활동과 증빙을 바탕으로 연구보고서를 작성하고 검토하도록 돕는 범용 AI 지침서입니다. 특정 연구대회나 플랫폼에 한정하지 않으며, 교육·현장실천 연구를 비롯한 사례·조사·실험 보고서에 맞춰 사용할 수 있습니다.

## 핵심 파일

**[통합 연구보고서 에이전트.md](./통합%20연구보고서%20에이전트.md)**

이 파일 하나에 역할, 원칙, 작업 절차, 문체, 자료 검증, 심사 관점 검토와 최종 점검표가 담겨 있습니다. README 없이도 지침서만 사용할 수 있습니다.

현재 설계 버전은 **1.1**입니다. 목적별 일관성 연결표를 필수 산출물로 지정하고, 자료 부족 시 행동, 수정 영향 점검, 완료 판정 조건과 가상 입력을 이용한 동작 검증 사례를 포함합니다.

## 사용 방법

1. 지침서 전체를 사용하는 AI 대화에 붙여넣거나 파일로 제공합니다.
2. 제출처의 최신 규정·서식·심사 기준과 비식별 처리한 연구 원고·자료를 제공합니다.
3. 원하는 작업 범위를 말합니다. 전체 구성, 부분 수정, 분량 압축, 결과표 정리, 정합성 검토 등이 가능합니다.
4. AI가 표시한 미확정 자료와 값을 연구자가 확인하고, 최종 편집본의 페이지·서식을 점검합니다.

전체 작성·검토 결과에는 **원고, 목적별 일관성 연결표, 주요 검토 사항, 남은 확인 사항과 완료 상태**가 포함됩니다. 짧은 부분 수정에는 필요한 항목만 적용합니다.

## 설계 검증 방법

AI에게 다음과 같이 요청할 수 있습니다.

```text
지침서 9장의 동작 검증 사례를 적용해 주세요.
각 가상 입력에 실제로 응답한 뒤, 필수 행동과 실패 기준에 대조해
사례별 충족 여부와 근거를 제시해 주세요.
검증 사례를 실제 연구결과로 사용하지 마세요.
```

검증 사례가 포함되어 있다는 사실만으로 성능을 검증한 것은 아닙니다. 사용하는 AI에서 응답을 확인하고, 미충족 행동이 있으면 지침을 보완하여 다시 확인합니다.

### 시작 요청 예시

```text
첨부한 통합 연구보고서 에이전트 지침을 적용해 주세요.
먼저 제출 규정과 자료 상태를 정리하고,
연구목적-문제-방법-결과-결론의 연결을 검토해 주세요.
제가 실제로 수행한 활동과 증빙을 최대한 살려 주세요.
확인되지 않은 수치와 사례는 만들지 말고 필요한 자료를 표시해 주세요.
이번 요청 범위는 [원하는 작업]입니다.
```

## 작성·검토 원칙

- **연구목적·본문 내용·결론의 일관성을 가장 먼저 점검합니다.** 목적에서 결과와 결론으로, 결론에서 근거로, 본문에서 목적으로 연결을 확인합니다.
- 규정과 지정 서식을 먼저 확인합니다.
- 실제 자료로 확인한 사실만 씁니다.
- 중간자료와 최종값을 구분합니다.
- 연구자의 활동과 증빙을 보존합니다.
- 구체적이고 담백한 문장과 필요한 표·도식·개조식을 사용합니다.
- 심사자 관점에서 근거, 해석과 한계를 검토합니다.
- 개인정보와 비공개자료를 보호합니다.

## 공개 범위

이 저장소는 범용 지침서와 사용 안내를 공유하기 위한 공간입니다. 실제 학생·참여자 자료, 학교 내부 문서, 연구 원자료, 사진, 계정·비밀번호·API 키는 포함하지 않습니다. 지침서를 사용하기 위해 실제 연구자료를 이 저장소에 올릴 필요는 없습니다.

이 파일을 제공하는 것만으로 AI가 자동 설치되거나 연구자료에 접근하지는 않습니다. AI 출력은 연구자가 원자료와 대조해야 하며, 제출처의 연구윤리·자료 이용·AI 활용 규정을 따릅니다.
